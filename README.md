# Automatisation de la création d’utilisateurs dans Microsoft Entra ID

Ce mini‑projet démontre comment automatiser la création d’utilisateurs dans **Microsoft Entra ID** à l’aide de **PowerShell** et du module **Microsoft Graph**.

Il s’agit d’un projet simple destiné aux environnements de test Microsoft 365, Intune ou Entra ID.

---

## 🎯 Objectifs du projet

- Automatiser la création de plusieurs utilisateurs dans Entra ID
- Préparer un lab Microsoft 365 / Intune
- Utiliser PowerShell et Microsoft Graph
- Démontrer une activité GitHub pour le Microsoft 365 Developer Program

---

- PowerShell 7+
